Smart Flood Early-Warning System

A prototype system that monitors flood conditions, activates a loud alarm, tracks the user's location with permission, and helps identify nearby safe places.

About the Project

🌧 Flood Monitoring

Simulates water-level monitoring through a digital flood sensor.

🔊 Loud Alarm

Activates a repeating warning sound when the flood level becomes dangerous.

📍 Location Tracking

Uses browser GPS permission to display the user's current coordinates.

🛟 Safe Place Finder

Creates a map-search link for nearby hospitals, shelters, and safe areas.

How It Works

1. Detect

Water level is monitored using a simulated sensor.

2. Process

The system checks whether the water level is normal, warning, or dangerous.

3. Alert

A visual warning and loud alarm are activated during dangerous conditions.

4. Locate

The browser requests location permission and displays the current position.

Prototype Architecture

Water-Level Sensor

Measures rising water levels in a real implementation.

Microcontroller

Processes sensor data and checks danger thresholds.

Communication Module

Sends alerts through Wi-Fi, GSM, or another communication network.

Alarm and Website

Produces warning sounds and displays flood information to users.
